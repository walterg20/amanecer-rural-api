# Amanecer Rural API — Mission

## Qué construimos
API REST del portal agropecuario Amanecer Rural. Backend principal que sirve datos a la web (Angular), la app móvil (Flutter) y el frontend SSR (Next.js).

## Para quién
- Productores agropecuarios (90% accede desde celular)
- Estudiantes del sector
- Empresarios y comerciantes agroindustriales
- Profesionales, laboratorios, funcionarios
- Administradores del sitio (gestión de contenido autogestionada por el cliente)

## Principios
- El cliente crea y gestiona su propio contenido — el CMS debe ser intuitivo
- Mobile-First absoluto — toda decisión de diseño prioriza mobile
- Interactividad media — formularios, suscripciones, comentarios (sin tiempo real)

## Stack
NestJS + TypeORM + PostgreSQL + Redis + JWT
