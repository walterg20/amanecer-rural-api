# Amanecer Rural API — Roadmap

## Fase 1 — Core (Indispensable)
1. 001-auth-roles — Sistema de autenticación con 3 roles (admin, editor, user)
2. 002-cms-content — CMS editorial con editor intuitivo para cliente no técnico
3. 008-pagos-mercadopago — Pasarela de pagos Mercado Pago (indispensable)
4. 012-data-migration — Migración de posts/páginas del sitio PHP actual

## Fase 2 — Portal + Marketplace
5. 003-remates — Gestión de remates (fechas, lotes, resultados)
6. 004-clasificados — Anuncios clasificados por rubro
7. 005-proveedores — Directorio de proveedores con perfiles
8. 006-eventos — Calendario de eventos con inscripción
9. 007-clima — Integración API de clima

## Fase 3 — Interacción y datos
10. 010-messaging-notifications — Mensajería interna (email-based, sin WebSocket)
11. 011-stats-reports — Panel de estadísticas y reportes

## Backlog
- 009-search — Buscador avanzado (no indispensable, diferido)
